# Deewid Landing V1

First public version of Deewid, a static ecommerce landing page built with HTML, CSS, and JavaScript.

This repository represents V1 of the Deewid project. It focuses on a simple marketing presentation that is easy to run locally, easy to adapt, and suitable for static hosting.

![Deewid Landing V1 Preview](./screenshots/home.png)

## Overview

- Static ecommerce landing page
- No backend required
- Local assets included
- Compatible with GitHub Pages
- Lightweight base for future design or product iterations

## Stack

- HTML
- Compiled CSS
- JavaScript
- Tailwind tooling for local workflow

## Run locally

```bash
npm install
npm run watch
```

The main entry point is [`index.html`](/F:/laragon/www/deewid-front/index.html).
