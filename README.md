# Deewid Landing V1

Premiere version publique de Deewid, une landing page e-commerce statique en HTML, CSS et JavaScript.

![Deewid Landing V1 Preview](./screenshots/home.png)

## Apercu

- Landing page statique orientee e-commerce
- Structure simple sans backend
- Assets locaux inclus
- Compatible avec GitHub Pages

## Stack

- HTML
- CSS compile
- JavaScript

## Demarrage local

```bash
npm install
npm run watch
```
