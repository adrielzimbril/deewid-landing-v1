# Deewid Landing V1

Première version publique de Deewid, une landing page e-commerce statique en HTML, CSS et JavaScript.

Cette version correspond à la V1 du projet. Elle se concentre sur une présentation marketing simple, rapide à ouvrir localement, facile à adapter, et compatible avec un déploiement statique.

![Deewid Landing V1 Preview](./screenshots/home.png)

## Aperçu

- Landing page statique orientée e-commerce
- Structure simple sans backend
- Assets locaux inclus
- Compatible avec GitHub Pages
- Base légère pour itérations design ou intégration future

## Stack

- HTML
- CSS compilé
- JavaScript
- Tailwind tooling pour le workflow local

## Démarrage local

```bash
npm install
npm run watch
```

Le site principal est servi depuis [`index.html`](/F:/laragon/www/deewid-front/index.html).
