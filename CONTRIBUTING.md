# Contributing

## Scope

This repository is the static V1 of Deewid. Keep contributions focused on:

- content quality
- visual polish
- accessibility
- static front-end fixes
- repository documentation

## Guidelines

- keep the project static
- avoid introducing backend dependencies
- preserve the Deewid and Oricodes references unless the change explicitly updates branding
- document meaningful changes in the README when they affect setup or scope

## Local workflow

```bash
npm install
npm run watch
```

## Pull requests

- keep changes scoped
- explain user-facing impact
- include screenshots when the UI changes materially
